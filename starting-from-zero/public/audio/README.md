# Audio

| File | Required? | What |
|---|---|---|
| `voiceover.mp3` (or `.wav`) | **Yes**, for the final render | Episode 01 narration downloaded from ElevenLabs |
| `music.mp3` (or `.wav`) | Optional | A licensed music track; it is ducked under the voice automatically |
| `sound-effects/` | Automatic | Generated by code; don't edit |

Future episodes: `audio/episode02/voiceover.mp3`, and so on (see `src/config/episodes.json`).
