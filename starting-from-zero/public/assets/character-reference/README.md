# Character reference photos

Put 1–3 clear photos of yourself here (front-facing and side profile work best, in good light, with your usual hair and beard).

Then ask Claude to "refine the character to match my reference photos". The changes go into `src/theme/character.ts` (and, if needed, `src/components/Character.tsx`), so every scene and episode updates at once.

Photos in this folder are ignored by git, so they stay on your machine.
