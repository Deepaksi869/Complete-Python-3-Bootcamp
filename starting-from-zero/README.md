# Starting From Zero: animated Reel generator

This folder turns an ElevenLabs narration into a finished, animated Instagram Reel (1080×1920, 30 fps, MP4). Everything is generated by code: the character, the scenes, the camera moves, the captions and the sound effects. You never edit a timeline.

---

## One-time setup

1. Install **Node.js 20 or newer** from https://nodejs.org.
2. In this folder, run:

```bash
npm install
```

You don't need to install ffmpeg. Remotion includes its own copy.

---

## Making Episode 01 (3 steps)

**Step 1: Create the narration in ElevenLabs.**
Paste the script from `src/config/episode01.ts` (or from the box below) and download the result as **MP3** (WAV also works).

**Step 2: Put the file here, using exactly this name:**

```
public/audio/voiceover.mp3
```

**Step 3: Run:**

```bash
npm run render:episode01
```

Your video appears at:

```
renders/starting-from-zero-episode-01.mp4
```

The command then:

- measures the narration
- fits every scene and caption to the voice
- renders the animation
- mixes in sound effects and music
- normalises loudness for Instagram
- checks the final file

If the narration file is missing, it stops and tells you where to put it.

### Preview before rendering

```bash
npm run preview:episode01
```

This opens Remotion Studio in your browser so you can scrub through the episode. It works even before you have narration; the timing is estimated until you add the file.

### Optional: music

Put a track you have the rights to use at `public/audio/music.mp3` (or `.wav`). It is automatically lowered while the voice is speaking and raised again in the pauses. Without music, the video still renders with narration and sound effects.

### Optional: visual draft without narration

```bash
npm run render:draft:episode01
```

This makes `renders/…-DRAFT-no-narration.mp4`, which is useful for checking the visuals.

## How the sync works

- The narration is **never sped up, slowed down or stretched.**
- Each script line is located in your audio using the natural pauses in the voice.
- The audio is only ever cut inside those pauses, and the scenes grow or shrink to fit.
- The video length follows your narration. Read at a natural pace, this script runs about **85–100 seconds**, not 55. If you want it shorter, use the *Speed* slider in ElevenLabs. The project adapts automatically.
- Captions are generated from the script, highlighted word by word, and kept inside Instagram's safe area.

> **Important:** the text in `src/config/episode01.ts` must match what ElevenLabs says. If you change a word in ElevenLabs, change it in the config too, so the captions stay correct.

---

## Changing the words

Open `src/config/episode01.ts` and edit the `text:` lines. Don't change the `id:` values (`p1`, `p2`, …), because the animation is synced to them.

---

## Making the next episode

1. Copy `src/config/episode01.ts` to `src/config/episode02.ts` and write the new script and scenes there.
2. Add an `episode02` entry to `src/config/episodes.json` with `"audioDir": "audio/episode02"`.
3. Put that episode's narration at `public/audio/episode02/voiceover.mp3`.
4. Register the composition in `src/Root.tsx` (copy the Episode01 block), and add `render:episode02` / `preview:episode02` scripts to `package.json`.
5. Reuse the existing sets (`src/sets/`) and scenes, or add new scenes in `src/scenes/` and register them in `src/scenes/registry.ts`.

The protagonist, colours, fonts, captions, sound effects and export settings are shared, so every episode automatically looks and sounds like the same series.

(Or ask Claude: *"Create episode 02 with this script …"*.)

---

## Making the character look like you

The protagonist is a provisional, stylised character. Put 1–3 clear photos of yourself in `public/assets/character-reference/` (front and side if possible), then ask Claude to refine the character. All of his features live in **one file**, `src/theme/character.ts`: skin tone, hair, beard, face proportions and clothes. A change there updates every scene in every episode.

## Project map

| Path | What it is |
|---|---|
| `src/config/episode01.ts` | **The script** and the scene list (edit this) |
| `src/config/episodes.json` | Audio folder and output file for each episode |
| `src/components/Character.tsx` | The reusable protagonist (poses, walk cycle, expressions, head turn) |
| `src/theme/` | Colours, fonts, character look, Instagram safe areas |
| `src/sets/` | Reusable environments: apartment, India office, airport, office entrance, rooftop |
| `src/scenes/` | The 7 scenes of Episode 01 |
| `src/components/` | Camera and parallax, typography, captions, laptop and phone UIs, transitions, sound |
| `src/lib/timeline.ts` | The engine that syncs scenes and captions to the narration |
| `scripts/` | Render, preview, narration measurement and sound-effect generator |
| `public/audio/` | **Your narration and music go here** |
| `renders/` | Finished videos |

Other commands: `npm run typecheck` checks the code, `npm run stills:episode01` makes contact sheets of the whole episode, and `npm run sfx` rebuilds the sound effects.

The fonts are Bebas Neue and Inter, both under the SIL Open Font License (see `public/fonts/`). All sound effects are synthesised by `scripts/generate-sfx.mjs`. No stock footage, stock audio or copyrighted music is included.
